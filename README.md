# Agentic Coding System

Agentic Coding is a framework for AI agents to autonomously contribute to software development projects with structured workflows, clear guidelines, and a focus on traceability and communication. This repository contains the core guidelines, skills, and tools for agents to effectively collaborate on coding tasks while adhering to best practices and maintaining alignment with human goals.

The skills, prompts, and scripts are located in the `agentic-coding` branch. See the contents at https://github.com/brandosha/agentic-coding/tree/agentic-coding

### Installation
```bash
curl -s https://raw.githubusercontent.com/brandosha/agentic-coding/refs/heads/main/setup.sh | bash
```

> It is not recommended to execute random scripts from the internet. Review the contents of [setup.sh](./setup.sh) before running it.
